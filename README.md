# TF-BVS Dataset Visualization Demo

This repository contains the interactive visualization demo for the TF-BVS breast ultrasound video segmentation dataset.

## Repository contents

- `index.html` - entry point for the interactive demo
- `assets/` - video frames, masks, and other demo assets
- `css/` - page styles
- `js/` - demo logic
- `Supplementary_Material.pdf` - supplementary paper material

The model implementation is intentionally not included in this public demo repository.

## Open the demo locally

1. Clone or download this repository.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Use the index slider to browse ultrasound video frames and their tumor-mask annotations.

The demo is self-contained and supports offline browsing after the repository has been downloaded.

## About TF-BVS

TF-BVS is a text-free inference framework for breast ultrasound video segmentation. The accompanying paper describes the benchmark dataset, training framework, and evaluation results.
